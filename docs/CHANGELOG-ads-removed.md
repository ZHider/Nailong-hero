# 变更记录：移除广告（2026-10）

## 背景

原版接的是 233 乐园 H5 激励视频（`https://cdn.233xyx.com/h5ad/metah5ad_v1.min.js`），
唯一用途是「死亡后看广告解锁重闯」。作者已离开该广告商，需要把整块能力摘掉，
同时**保留失败界面的「再来一次」按钮和交互**，只是不再需要看广告。

## 行为变化

| 场景 | 改之前 | 改之后 |
| --- | --- | --- |
| 死亡后点「再来一次」 | 先拉激励视频，看完才变成「点击重闯本关」，再点一次才重闯 | 点一下立刻从本区域入口重闯 |
| 广告播放中 | 静音、暂停 BGM、全屏按钮禁用、Esc 被忽略 | 不再存在这种状态 |
| 非投放环境（普通浏览器） | 提示「请在 233 乐园中打开」，**无法重闯** | 正常重闯 |
| 失败界面 | 按钮文案「看完广告再闯一次」+ 一行 `#death-ad-note` 状态说明 | 按钮文案「再来一次」，无额外说明行 |

## 删除的代码（`src/main.js`）

1. **SDK 适配层**（原 622-731 行）
   `St`（广告位类型）、`ce`（状态码表）、`Ss`（SDK 地址）、`z()`（失败结果）、`Je()`/`He()`
   （取 SDK / 可用性判断）、`be()`/`Be()`/`Es()`（回调解析）、`jt()`（日志垫片）、
   `Ts()`（动态加载 SDK）、`Ls()`（iOS 关闭回调判断）、`Et()`（超时包装）、`Tt()`（数值兜底）。
2. **广告管理器** `class Ms`（原 737-891）+ 单例 `Ps` / `Cs` / `Ds`：lease 生命周期、
   `isAdSupport`/`showAd` 调用、状态映射。
3. **复活调度** `class $s`（原 898-945）+ 单例 `_`：按 `runToken + 死亡次数` 去重、在途请求 abort。
4. **广告状态变量**：`he`（runToken）、`N`（广告进行中）、`_t`（死亡次数）、`ae`（代次）、
   `ue`（已看完待确认），以及生成 runToken 的 `ot()`。
5. **联动点**：
   - `I()`（应用设置）里的 `!N && !_.adActive` 音量门控
   - `Ft()`（返回标题）里的 `_.invalidate()`
   - `[data-action="fullscreen"]` 的 `N || _.adActive` 拦截
   - `Rs(...)` 视口适配的 `() => N || _.adActive` 回调（改为 `() => !1`）
   - Esc 键处理里的 `|| N`
   - `_.subscribeAdActivity(() => { B && I() })`
6. **UI/样式**：失败界面的 `#death-ad-note` 元素、按钮里「看完广告再闯一次」文案、
   `src/styles/game.css` 中的 `.leyuan-ad-note` 规则。

## 保留的代码

- `[data-action="retry"]` 按钮及其 `Pa()` 处理函数、`Ca()` 里的失败文案分级
  （第一次/第二次/第三次死亡的三种台词）、`w.save()` 与「本机进度未能保存」提示。
- 重闯语义不变：`Z.enter()`（全屏）→ `M('')`（关闭弹窗）→ `w.retry()`（回到本区域入口，
  保留进区域时的强化）→ `I()`（刷新设置）。

## 验证

1. `pnpm build` 通过，产物里不再包含 `metah5ad` 字样。
2. 浏览器实跑（`pnpm preview`）：
   - 开局站桩不动约 25 秒 → 血量归零 → 出现失败界面，按钮显示「再来一次」，无 `#death-ad-note`
   - 点击按钮 → **立即**回到第 1 章第 1 波（不再有广告步骤），HUD 正常刷新
   - 控制台无报错（只有 Phaser/WebGL 常规日志）
3. `pnpm verify` 差异清单：main.js 共 31 处（12 改动 / 18 删除 / 1 新增），
   全部落在上述广告相关语句；`pnpm verify:core` 只剩还原时的 5 处构建期改写。

## 回滚

```bash
git log --oneline          # 找到 "feat: 移除广告" 之前的一个 commit
git revert <广告移除的 commit>
```
